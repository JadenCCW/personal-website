I rebuilt this site. The old one was a single page with anchor links pretending
to be tabs; this one has real pages, no JavaScript, and one stylesheet I can
read top to bottom.

Everything here is a markdown file in a folder. Adding a post means adding a
file. Adding a photo means dropping it in a directory. That's the whole system,
and it's the part I most wanted to get right — the last site was easy to look at
and annoying to update, so I never updated it.

More soon, hopefully.
